# Idea Incubation & Pre-Project Synthesis

> **Memory Tier**: Working Memory (`wiki/working/incubation/`)

This directory serves as the collaborative scratchpad for the JP AI Future Study Group. It is the space where ideas are synthesized, seminar learnings are aggregated, and preliminary research is incubated **before** they mature into formal projects.

## Purpose

The 6-stage project loop (in `projects/`) requires a high degree of structure, starting with a locked `intent.md` and `spec.md`. However, not all ideas are ready for that level of rigor immediately. 

Use this directory to:
- Synthesize findings from multiple seminar sessions (e.g., merging insights from the Neuro-AI and Compute seminars).
- Maintain running topic scratchpads (e.g., `scratchpad-ai-governance.md`).
- Draft early "Evidence Matrices" comparing different sources before formalizing a whitepaper project.
- Incubate potential project ideas until they have a clear audience and objective.

## Workflow

1. **Create a Scratchpad**: Open a new markdown file here (e.g., `synthesis-ai-talent-pipelines.md`).
2. **Link to Sources**: Liberally use `[[wiki-links]]` to connect to `wiki/semantic/sources/` or `wiki/episodic/` notes.
3. **Graduate to a Project**: Once the synthesis reveals a clear, actionable deliverable (policy brief, curriculum, etc.), use the insights here to write the `intent.md` and `spec.md` in a new project folder under `projects/`. The scratchpad remains here as a historical record of the incubation process.
